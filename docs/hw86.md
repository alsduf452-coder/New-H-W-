# 8.6G H/W 연결 (classic-cloud)

8G → 설비 H/W 이력관리에서 8.6G A6 BP-04를 조회합니다.
기존 6G 및 8G PENDING 파일과 별개 소스 hw-86으로 저장됩니다.

## 설치

1. Render hw-excel-sync-classic을 최신 classic-cloud로 배포합니다.
2. 기존 SYNC_SOURCES_JSON 항목들을 보존하면서 `"hw-86":{"mode":"hw86"}`을 추가합니다.
3. PC에서 반드시 local_sync 폴더로 이동한 후 agent.py, daily_sync.py, manual_sync.py를 업데이트합니다.
4. 기존 config.toml 최상위에 아래 두 줄을 추가합니다. 실제 폴더 경로를 사용합니다.

```toml
hw86_excel_path = 'Q:\실제폴더\A6_BP_04_결과_공정_라인_v*_*.xlsx'
hw86_source_id = 'hw-86'
```

5. `.\.venv\Scripts\python.exe .\agent.py --config .\config.toml --once`로 최초 전송합니다.
6. 로그의 [8.6G H/W] 전송 완료와 앱의 수신 시간을 확인합니다.

기본 소스 ID 사용 시 Streamlit Secrets 추가는 필요하지 않습니다. 다른 ID를 사용하면
[local_excel] hw86_source_id를 PC와 서버 설정에 맞춥니다.
기존 09:00 예약 및 수동 요청 작업에 8.6G 파일이 추가됩니다. 부재/일시정지/실패 시 중단 규칙은 유지합니다.
비활성화된 수동 작업을 이 업데이트가 다시 활성화하지는 않습니다.

## 데이터 해석

- Diffuser Flat., Susceptor Flat., Spacing, Shim 변경이력만 파싱합니다.
- Excel 원본을 수정하지 않습니다. 제목이 편차인 블록과 입력용/Backing Plate 블록은 제외합니다.
- 다른 시트 및 원본 편차 표를 서버 스냅샷에 저장하지 않습니다.
- 숫자 0과 음수는 그대로 보존합니다. X/미측정/빈칸은 null로 취급합니다.
- 일반 Flatness 5×7, TTS 원본 7×7, 별도 변환표 5×7을 구분합니다.
- 측정값을 반복 배치한 참고 블록도 원본 셀 위치와 제목으로 구별해 보존합니다.
- Spacing 불규칙 위치와 Shim 추가 위치는 희소 배열로 보존합니다. 임의의 9점 위치로 재배열하지 않습니다.
- Shim 화살표와 가공 설명은 원문 메모로 남깁니다. 숫자를 추측해 두께로 넣지 않습니다.
- 년도 없는 09/16 및 날짜 없는 기록은 날짜 확인 필요로 표시합니다. 파일명에서 날짜를 추정하지 않습니다.
- 중앙값은 통계적 median이 아닌 배열 중앙 측정점입니다. Max−Min은 유효 실측값 범위입니다.
- 편차는 상세 기록 − 기준 기록입니다. 같은 항목/같은 배열 크기의 동일 상대 위치끼리만 계산합니다.
  한쪽이 미측정이면 결과도 빈칸입니다. 다른 온도/압력 조건 비교 시 안내합니다.
- 숫자는 원본 단위를 유지하며 단위를 임의 변환하지 않습니다.
